# okurenes.github.io

Enes Okur'un geliştirici sitesi: https://okurenes.github.io (GitHub Pages, `main` dalının kökü).

- `index.html`: oyunların listesi ve iletişim.
- `dokuma/`: Dokuma'nın tanıtım ve destek sayfası, gizlilik politikası ve görseller. Elle düzenlenmez; oyunun deposunda `node tools/site.mjs ../okurenes.github.io` ile güncellenir.
- `app-ads.txt`: AdMob yayıncı satırı (AdMob hesabı açılınca aynı araç ekler).
